# 《我们》私人艺术馆

纯静态网站：HTML + CSS + 原生 JS，不依赖任何框架、CDN 或外部字体，国内任何静态托管都能直接部署。

以翻页展厅串联回忆：页面平滑滚动并停靠到章节位置，照片瀑布流缓慢自动往返滚动，鼠标悬停或手动操作时暂停。
交互卡片使用液态玻璃和悬停轻浮效果；左侧放大留声机提供六首本地原创钢琴曲，首次点击后按列表循环播放。

## 日期都是算出来的，不用每天改文件

「在一起 169 天」「距下一个 5.20 还有 196 天」这些数字**没有一行是写死的**：
页面加载时用访客本机的时钟现算（`togetherSince` + `today()`），所以传到域名上之后会自己走。

- 换了日期（零点）→ 下次打开就是新的数字
- 标签页开着一整夜 → 跨过零点会自动重算，切回标签页时也会再算一次
- 生日 / 纪念日按「月-日」每年轮一次，当天会显示「今天」

要改就只改 `data.js` 的 `togetherSince` 和 `dates-data.js` 里的日期，别去改数字。

> 唯一会让数字「看起来没更新」的是浏览器/CDN 缓存了旧的 JS。
> 上传后如果还显示旧值，跑一遍 `us-gallery-deploy/purge.mjs`（或强刷一次）。

### 01 去过的地方

- 地图是**一条线**：`js/china-map.js` 里 `window.CHINA_MAP`，手工按经纬度描的点
  （大陆 91 个 + 台湾 9 个 + 海南 10 个），用中点二次平滑连成闭合曲线，
  投影是等距圆柱 + 中纬余弦（`x=(lng-73)×15.876`，`y=(54-lat)×19.38`），
  viewBox `0 0 1000 717`。不是精确边界，只求像。
- 城市在 `data.js` 的 `places`（经纬度），用同一个 `CHINA_MAP.project()` 落点，**不连线**。
- 东边六个（菏泽/青岛/烟台/济南/泰安/徐州）挤在一小块，点上不压字；
  名字放在右边一列，鼠标指到哪一行，地图上那个点就加亮（`.pin.is-hot`）。
- 换城市：改 `places` 里的经纬度即可，地图不会动。
- 重新描轮廓：改 `us-gallery-tools/gen-china-map.cjs` 里的点数组，跑一遍覆盖 `js/china-map.js`。

### 02 一起的日常

- 吃饭回忆在 `assets/food/` 与 `js/food-data.js`，游玩回忆在 `assets/play/` 与 `js/play-data.js`；两组按各自原有的时间顺序交错展示。
- 分类按钮可筛选「一起吃饭」或「一起玩」。卡片保持照片原始比例，栅格在桌面、平板和手机分别采用 4、3、2 或 1 列。
- 点击卡片会打开详情层，显示原图、标题与完整文字；图片懒加载，瀑布流缓慢自动上下滚动，鼠标悬停、触摸或手动滚动时暂停。
- 深链 `#p-food`、`#p-play` 仍可用，会跳转到「日常」并选中对应分类。
- 新增条目时，把图片放入对应目录，再编辑相应的 `js/*-data.js`；编号和数组顺序沿用现有时间顺序。

### 03 时间长廊

- 内容来自 `D:\回忆\时间.txt`，生成到 `js/time-data.js` 的 `window.TIMELINE`：
  每条 `{ date: 'YYYY-MM-DD', title, text }`，现在是 8 条（2026.5.6 → 2026.10.24）。
- 行里显示 `日期 + 标题 + 正文第一行`（单行省略），点开是详情层里的完整一段，可以翻上一条/下一条。
- 8 条会把一屏撑破，所以 `#p-time` 单独收紧了上下边距和行距（1600×900 正好 900，
  1280×720 是 720；手机上仍会比屏幕高，靠原有的「比视口高的页可以停在中间」逻辑滚动）。

## 怎么翻

- 滚轮 / 触控板：自然滚动；封面与地点页之间停下时会贴合到其中一页
- 键盘：↑ ↓ PageUp PageDown ← → Home End
- 右侧圆点、右上角进度、点「回到封面」都能直接跳页
- 手机：原生滑动；封面与地点页之间会停靠，其余内容自由滚动
- 深链：`index.html#p-dates` 直接打开某一页，翻页时会自动更新地址栏

滚轮和触控都使用自然滚动。只有封面与第 01 页「地点」之间保留章节停靠；进入地点页后，其余章节都可连续滚动浏览。

## 改样式

- **配色**：`css/style.css` 顶部 `:root`。底色采用轻微暖调的浅象牙白，香槟金只作少量强调。
- 页面切换：没有粒子转场；只有封面和地点页之间保留章节停靠。
- **视差**：任意元素加 `data-par="0.12"`（纵向）、`data-parx="0.24"`（横向）、`data-pars="0.05"`（缩放）。
  数值是「偏离视口中心一屏时移动多少屏」，正负决定方向。只用于页码幽灵等装饰层。
- **液态玻璃**：`.glass` 一个类。可调 `--ga` 玻璃体不透明度、`--gi` 高光强度、`--gblur` 模糊、`--gr` 圆角、`--gtint` 底色；
  `.glass--pill` 药丸、`.glass--tilt` 带指针倾斜、`.glass--wide` 大圆角。
  `js/glass.js` 负责把 `--gx/--gy` 写到指针位置（只在有鼠标的设备上启用）。

### 04 纪念日

五张卡，`since` 是「从那天起过了多少天」，`annual` 是「距下一次还有多少天」：

| 卡 | 日期 | mode |
| --- | --- | --- |
| 我们的纪念日 | 2026-05-20 | annual |
| 我们在一起 | 2026-05-20 | since |
| 你的生日 | 2026-06-30 | annual |
| 我的生日 | 2026-04-07 | annual |
| 我们重逢的日子 | 2026-05-06 | since |

- 照片：放进 `assets/photos/`，在对应条目里填 `'assets/photos/文件名.jpg'`。留空时显示艺术化占位。建议照片长边压到 2000px 以内、单张 500KB 以内。
- 音乐：左侧留声机使用 `assets/music/` 中的六首本地原创钢琴曲；首次点击后播放，顺序结束后回到第一首继续循环。
- 页数变了（增删 `<section class="page">`）时，右上角 `01 / 06` 和右侧圆点会自动跟着变，不用手改。

## 上线（国内访问）

1. 把整个 `us-gallery` 文件夹上传到阿里云 OSS、腾讯云 COS 或七牛云的静态网站托管。
2. 在中国大陆用自己的域名访问需要 ICP 备案。不想备案的话，可以用托管商提供的默认域名，或者选香港节点（速度稍慢，但不需要备案）。
3. 用最终网址生成二维码。
