# 我们的小小歌单

六首为本网站生成的原创钢琴风格纯音乐小品，没有人声，没有引用已有歌曲旋律或商业录音。
每首使用独立旋律、和弦、拍号或节奏；声音由程序合成拨弦式钢琴音色，并加入轻微房间混响。

| 曲目 | 文件 |
| --- | --- |
| 初见的光 | `01-first-light.wav` |
| 慢慢的午后 | `02-slow-afternoon.wav` |
| 同一把伞 | `03-under-one-umbrella.wav` |
| 海边的晚风 | `04-evening-by-the-sea.wav` |
| 写给你的信 | `05-a-letter-to-you.wav` |
| 明天也和你 | `06-tomorrow-with-you.wav` |

点击页面左侧橙色播放按钮开始，顺序播放六首，然后回到第一首；暂停后从当前位置继续。
歌单按钮可以选择曲目、上一首、下一首。播放器不依赖外部音乐平台或 API。

所有音频为 22,050 Hz、16-bit PCM、单声道 WAV。可直接上传静态网站托管。
`generate.py` 是可复现的音频生成脚本（需要 Python 和 NumPy），`tracks.json` 记录准确时长。

如需换成自选歌曲，把拥有使用权的文件放入本目录，再修改 `js/music.js` 中的六项配置即可。
